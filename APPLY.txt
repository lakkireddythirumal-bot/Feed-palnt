Important:
This ZIP is a PATCH package, not a replacement for the whole website.
Keep the current GitHub app.js because it contains your latest dashboard work.

ROOT CAUSE FOUND
----------------
The current app.js can read the Supabase JSONB fields, but the closing-value
path depends on the transaction parser. If the JSONB shape is slightly
different, material names load while numeric values become null.

There is also a service-worker cache-first path for app.js/style.css. That can
keep an older JavaScript version running even after GitHub was updated.

FIXES INCLUDED
--------------
1. Dynamic JSONB numeric parser for nested objects/arrays/JSON strings.
2. Direct Closing fallback from latest_activity.
3. Robust detail-value extraction.
4. Service-worker cache version bump + network-first for app.js/style.css.
5. No fixed material list and no Supabase schema change.
